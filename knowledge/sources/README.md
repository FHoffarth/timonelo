# Sources

- **Purpose:** Organize source records supporting knowledge claims.
- **Scope:** Source identity, provenance, access details, and review status.
- **Allowed content:** Source metadata and evidence references.
- **Forbidden content:** Unlicensed copies, unsupported claims, or application code.
- **Naming convention:** Use `source-<organization>-<short-title>.md` in lowercase kebab-case.
