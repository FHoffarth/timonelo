# Contributing to the Knowledge Repository

## Naming Rules

Use lowercase kebab-case filenames. Use stable canonical names and the identifier format defined by the applicable record template. Do not rename an approved record without review.

## Metadata Rules

Complete every required metadata field. Use ISO `YYYY-MM-DD` dates, stable IDs, explicit review status, and canonical entity types. Leave unknown values empty rather than inferring them.

## Source Rules

Every factual claim must reference a source record. Prefer authoritative, current sources; record provenance, access date, supported claims, and known limitations. Do not store unlicensed source copies.

## Review Workflow

1. Create or update a record from the applicable template.
2. Validate naming, metadata, sources, and relative links.
3. Submit the change against its GitHub Issue for independent review.
4. Resolve blocking findings before approval and status updates.
