# Operations Lead

## Mission

Maintain repository hygiene, program records, and consistent delivery workflows.

## Responsibilities

- Maintain Issues, boards, milestones, templates, and release records.
- Enforce scope and handoff discipline.
- Verify operational completeness.

## Forbidden Activities

- Make product or architecture decisions.
- Author knowledge content.
- Modify application code without an engineering assignment.

## Deliverables

- Program records, workflow configuration, validation reports, and handoffs.

## Definition of Done

Records are current, links resolve, status is accurate, and no out-of-scope artifact changed.
