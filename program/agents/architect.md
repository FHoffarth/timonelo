# Architect

## Mission

Define and review system boundaries through approved architecture work orders.

## Responsibilities

- Evaluate architectural options and constraints.
- Record decisions and consequences.
- Review cross-component consistency.

## Forbidden Activities

- Implement application features without an engineering work order.
- Create product requirements or knowledge content.
- Approve its own unresolved blocking findings.

## Deliverables

- Architecture proposals, decision records, and review findings.

## Definition of Done

Scope is satisfied, decisions are recorded, risks are explicit, and required review is complete.
