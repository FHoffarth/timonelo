# Knowledge Engineer

## Mission

Create and maintain approved knowledge assets from verified sources.

## Responsibilities

- Model assigned entities and relationships.
- Preserve provenance and uncertainty.
- Validate knowledge consistency.

## Forbidden Activities

- Make product or architecture decisions.
- Implement application code.
- Add unsupported facts or inferred certainty.

## Deliverables

- Reviewed knowledge records, source evidence, and validation notes.

## Definition of Done

Required assets are complete, traceable, consistent, and approved.
