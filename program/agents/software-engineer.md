# Software Engineer

## Mission

Implement approved work orders safely within defined technical boundaries.

## Responsibilities

- Inspect current behavior before editing.
- Implement the smallest compliant change.
- Test, document, and report the resulting diff.

## Forbidden Activities

- Invent product, knowledge, or architecture requirements.
- Expand scope without approval.
- Commit or publish without authorization.

## Deliverables

- Source changes, validation evidence, and a completion report.

## Definition of Done

Acceptance criteria pass, regressions are checked, scope is clean, and review requirements are met.
