# Timonelo Canon

---

## 1. Core Axiom

> **Timonelo must never sound more certain than its evidence.**

Every conclusion must be traceable to a source, mathematical derivation, or explicit rule. Missing evidence must remain explicitly missing. Geometric exposure must not be presented as measured physical experience. A limitation is an essential part of the answer, not a footnote.

---

## 2. The Four Epistemic Tiers

Timonelo separates data into four non-overlapping epistemic states:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          THE EPISTEMIC TIERS                                │
│                                                                             │
│               [ LEVEL 4: EXPERIENCE READY ] ── Ship Level                   │
│               [ LEVEL 3: VERIFIED ]        ── Coordinate Level              │
│               [ LEVEL 2: CANONICAL ]       ── Archetype Level               │
│               [ LEVEL 1: UNKNOWN ]         ── Explicit Void                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **Canonical**: An architectural fact, polygon, or spatial rule established as mathematical truth for a class of ships (an Archetype). Inherited across sister vessels until a vessel-specific mutation is documented.
2. **Verified**: A specific physical attribute on an exact vessel corroborated by at least two independent primary-source evidence artifacts (e.g., naval GA drawing + physical survey photograph).
3. **Unknown**: An active, first-class status signifying that evidence does not meet publication thresholds. Rendered as an honest architectural void, never guessed or hallucinated.
4. **Experience Ready**: The certification awarded to a ship when 100% of public/residential decks, staterooms, overhead sandwiches, and wayfinding graphs pass the complete quality audit.

## 3. Terminology Canon

Timonelo enforces single-meaning terminology across all documentation, code, and user interfaces:

| Canonical Term | Strict Meaning | Forbidden Synonyms |
| :--- | :--- | :--- |
| **Deck** | A horizontal floor level on a maritime vessel. | Floor, Level, Story, Layer, Tier |
| **Cabin** | A passenger's private living quarters on board. | Room, Hotel Room, Accommodation Unit |
| **Stateroom** | Used exclusively when classifying archetype series. | Fancy Cabin, Premium Room, Luxury Berth |
| **Suite** | A multi-room or upgraded stateroom with dedicated zones. | VIP Room, Deluxe Flat, Penthouse Berth |
| **Port** | The left side of the vessel when facing the Bow (Prow). | Left, Left-hand side, Red side |
| **Starboard** | The right side of the vessel when facing the Bow (Prow). | Right, Right-hand side, Green side |
| **Forward** | Toward the front (Bow) of the ship's hull. | Front, Front-end, Head of ship |
| **Aft** | Toward the rear (Stern) of the ship's hull. | Back, Rear, Stern-side, Tail |
| **Midship** | The central structural section between Forward and Aft. | Middle, Center, Mid-deck |
| **Atrium** | Multi-deck open architectural vertical void. | Lobby, Hall, Reception Area, Foyer |
| **Promenade** | Wide public interior or exterior thoroughfare. | Shopping Mall, Street, Boulevard, Strip |
| **Bulkhead** | Structural vertical partition dividing spaces. | Wall, Partition Wall, Divider, Board |
| **Venue** | Any dedicated public dining, drinking, or activity space. | Facility, Place, Spot, Outlet |

## 4. The 20 Spatial Laws

1. **Spatial truth before visual beauty.**
2. **Unknown before hallucinated.**
3. **Orientation before information.**
4. **Context before recommendation.**
5. **Coordinates before pixels.**
6. **Vector precision before raster convenience.**
7. **The ship is a 3D volume, never a flat page.**
8. **A cabin is defined by what surrounds it.**
9. **Sightlines are mathematical rays, not subjective opinions.**
10. **The passenger’s sense of direction is sacred.**
11. **Port and Starboard are structural absolutes.**
12. **Vertical movement requires as much cognitive care as horizontal.**
13. **Every door must connect to a walkable circulation graph.**
14. **Overhangs, bulkheads, and lifeboats are physical realities.**
15. **Archetypes govern geometry; vessels govern mutations.**
16. **Missing data is represented honestly as an architectural void.**
17. **The engine operates entirely offline without server dependence.**
18. **Accessibility is an intrinsic graph filter, not an afterthought.**
19. **Real daylight and horizon angles outshine artificial rendering.**
20. **Timonelo preserves the spatial truth for the lifetime of the vessel.**
