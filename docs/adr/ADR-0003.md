# ADR-0003 — Runtime & Determinism

This ADR defines **how the engine computes, caches, and proves itself**. It
takes the truth model of ADR-0002 as given and adds no epistemology.

## Status

**Proposed.** Becomes binding when merged. The acceptance criteria in §5 and §6
are the definition of done for Milestone D14.

---

## 1. Scope boundary

| Concern | Owner |
|---|---|
| What constitutes a statement | ADR-0002 |
| Confidence propagation *semantics* | ADR-0002 |
| Confidence propagation *implementation and caching* | ADR-0003 |
| Statement reproducibility (semantic equality) | ADR-0002 §4 |
| Artifact determinism (byte equality) | ADR-0003 §5 |

The two equalities are distinct and may diverge deliberately. A serialization
refactor may break byte equality while every statement remains identical in
meaning: permitted here, a non-event under ADR-0002.

**A failing determinism test is never repaired by modifying an inference rule.**
That inverts the dependency and corrupts the truth model to satisfy a cache.

---

## 2. The Inference Graph is a cache

The materialized inference view is **derived, disposable, and rebuildable from
the three persistent stores alone**. It may be deleted at any time without loss.

Persisting derived confidence is the drift mechanism ADR-0002 exists to
eliminate. Two stores of the same quantity diverge as soon as one rebuild is
skipped.

```
Question Registry  ─┐
Evidence Event Log ─┼─→  [rebuild]  →  Ground Truth
Rule Set           ─┤                  Hypothesis Store
                    └                  Inference Graph
```

Each build artifact is stamped with the versions of all inputs that produced it,
including `as_of`. An artifact whose stamp does not match the current store
versions is **stale and unusable** — it must not be served with a warning, it
must not be served at all.

---

## 3. Rule versioning

Rules are content-addressed. A derived statement cites the **hash** of the rule
version it consumed, never the rule's name.

Citing `INFERENCE_RULE_17` by name reintroduces exactly the defect ADR-0002
removes: the citation points at an artifact that may no longer say what it said
when the statement was produced. This is a fake hash in a new costume.

Editing a rule produces a new hash, invalidating every statement in its closure.
This is intended and must appear in the rebuild diff.

---

## 4. Derivation closure

Every derived statement persists the IDs of **every input it consumed**,
transitively resolvable.

Cost: roughly a doubling of the inference graph's size. Accepted knowingly.
Without the closure, the blast-radius criterion (§6) is unverifiable and
inspectability (ADR-0002 §10, condition 3) is unimplementable.

The closure is what makes the graph a graph rather than a table of results.

---

## 5. Acceptance criterion — determinism

```
hash(questions@v) + hash(events@v) + hash(rules@v) + as_of
    → byte-identical inference graph
```

**Procedure.** Delete the materialized view. Rebuild. Compare bytes.

### 5.1 Canonical form is mandatory

This criterion will fail on serialization long before it fails on logic. The
following are requirements, not recommendations:

- **Sorted keys throughout.** No reliance on dict or set iteration order at any
  layer, including intermediate structures never serialized.
- **Fixed float formatting.** No bare `repr()`. A single format function,
  applied everywhere.
- **No clock reads inside the build.** Any wall-clock timestamp embedded in an
  artifact breaks byte equality on the second run. `evidence.py`'s
  `verified_on="2026-08-16"` default is an instance of this today.
- **No absolute paths, hostnames, usernames, or environment values** in output.
- **No PRNG.** If any generator requires randomness, its seed is an explicit
  versioned input.

### 5.2 Ordering of min-propagation

`min()` over a set is order-independent for exact values, but
`min(inputs) × rule.defeasibility` involves floating-point multiplication.
Fix the traversal order (topological, ties broken by statement ID) so the
sequence of operations is itself deterministic.

---

## 6. Acceptance criterion — blast radius

**Procedure.** Modify one evidence event. Rebuild. Diff.

**Only statements whose derivation closure contains that event may change.**

Any change outside that closure is a defect — typically hidden global state,
iteration-order dependence, or an undeclared input to a rule. This criterion is
strictly stronger than §5 and catches a class of error determinism alone cannot:
a build can be perfectly reproducible and still wrong in its dependency
structure.

Both criteria run in CI on every commit touching `factory/`, `calculus/`, rules,
or the ontology.

---

## 7. Runtime invariants

- **R1 — `as_of` flows downward only.** The clock is read once at the request
  boundary. No component beneath it may read a clock.
- **R2 — Confidence exists only in memory.** No serialized structure in any
  persistent store contains a confidence value. The inference graph may cache
  computed confidence; the graph is a cache.
- **R3 — Stale artifacts are not served.** Version-stamp mismatch is a failure,
  not a warning.
- **R4 — Generators write only to the Hypothesis Store.** No code path exists
  from a generator to Ground Truth. Promotion requires an evidence event
  (ADR-0002 §5.1).
- **R5 — Rebuild is total.** Incremental rebuild is not adopted at this stage.
  It is a performance optimization that would compromise §5 and §6 before either
  has ever passed. Revisit only after Milestone D14, in a separate ADR.

---

## 9. Consequences

- Full rebuilds become the only build mode. At current scale (four vessels, 327
  knowledge files) this is acceptable. It will require revisiting well before
  hundreds of vessels, and that revisit is a deliberate ADR, not an incremental
  patch.
- Inference graph size roughly doubles from closure tracking.
- Canonical form imposes discipline on every serialization site. Cheap now;
  miserable to retrofit.
- CI runtime increases by the cost of two full rebuilds per relevant commit.

---

## 10. Why these two criteria are the product

Determinism and blast radius are what convert "we do not invent" from a claim
into a property.

An auditor — a cruise line's legal team, a port authority, a partner — can be
handed the three stores and independently reproduce every statement the system
has ever shown a passenger. That is not a testing convenience. It is the
commercial argument, and no amount of interface work substitutes for it.
