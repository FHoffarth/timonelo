# Timonelo Roadmap

---

## 1. Milestone Framework

The Timonelo roadmap is milestone-based. Progress is driven by validated implementation and evidence rather than speculative calendar dates.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            MILESTONE PROGRESSION                            │
│                                                                             │
│  [ M0: REPOSITORY ] ────────── Python Package, Tests & Base Architecture    │
│  [ M1: LANDING PAGE ] ──────── Public Explanation & Independence Standard   │
│  [ M2: SPATIAL ENGINE ] ────── Deterministic Spatial Contracts & Models     │
│  [ M3: CANONICAL EXPLORER ] ── Knowledge Pack v1 & Explorer MVP (Meraviglia)│
│  [ M4: FOUNDATION FREEZE ] ─── v1.0 Foundations & Governance Sealed (CURRENT)│
│  [ M5: MULTI-SHIP FACTORY ] ── Master Archetypes & Pipeline Automation      │
│  [ M6: PUBLIC RELEASE ] ────── Multi-Ship Explorer & Community Ingestion    │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 2. Milestone Execution

### M0 — Foundation & Repository (Completed ✓)
Establish project foundation: product direction, architectural boundaries, data conventions, packaging metadata, and minimal testable Python package.

### M1 — Landing Page (Completed ✓)
Publish a restrained, static explanation of Timonelo's purpose, independence, evidence standard, and availability.

### M2 — Spatial Evidence Engine Integration (Completed ✓)
Integrate deterministic spatial algorithms behind explicit input, output, provenance, and validation contracts.

### M3 — Canonical Knowledge Pack & Explorer MVP (Completed ✓)
Establish the canonical `src/timonelo/knowledge_pack` schema and deploy the Cruise Explorer MVP with zero-CLS performance and deep orientation routing.

### M4 — Foundation Freeze v1.0 (Current Status ✓)
* **Objective**: Formally seal the Timonelo Foundations documentation suite (`CANON.md`, `MANIFESTO.md`, `PRODUCT.md`, `ARCHITECTURE.md`, `ENGINEERING_PRINCIPLES.md`, `TRUST_FRAMEWORK.md`, `CONTRIBUTING.md`).
* **Governance**: Core architectural boundaries, schema contracts, and epistemic definitions are frozen. Any future alterations require a formal Pull Request.

---

## 3. Active & Upcoming Milestones

### M5 — Multi-Ship Knowledge Factory (Active)
* Industrialize ingestion using the Master Archetype inheritance model.
* Support sister-ship delta compilation without duplicating baseline CAD layouts.
* Expand the Knowledge Factory test suite and source validation tooling.

### M6 — Public Release & Verification Pipeline (Next)
* Deploy multi-ship explorer profiles to production.
* Establish formal peer-review tooling for contributor evidence intake.
* Release offline-capable packaging for low-bandwidth environments.
