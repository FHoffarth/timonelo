# Roadmap

The roadmap is milestone-based. Dates and implementation choices will be set only when the preceding milestone has produced enough evidence to justify them.

## M0 — Repository

Establish the project foundation: product direction, architectural boundaries, data conventions, packaging metadata, and a minimal testable Python package.

**Complete when:** the repository can be installed locally, its documentation is internally consistent, and no product behavior has been implied without implementation.

## M1 — Landing Page

Publish a restrained, static explanation of Timonelo's purpose, independence, evidence standard, and current availability.

**Complete when:** a visitor can understand what Timonelo does, what it does not do, and how evidence limitations are handled.

## M2 — Spatial Evidence Engine Integration

Integrate the existing deterministic spatial research into Timonelo behind explicit input, output, provenance, and validation contracts.

**Complete when:** a supported ship dataset produces reproducible evidence artifacts without product-layer interpretation.

## M3 — Cabin Briefing MVP

Define and generate the first complete Cabin Briefing for a bounded set of cabins and evidence sections.

**Complete when:** every published statement is traceable, unsupported sections remain explicit, and briefings can be regenerated deterministically.

## M4 — Multi-Ship Support

Extend ingestion and validation to multiple ships without adding ship-specific logic to shared algorithms.

**Complete when:** ship profiles remain external to the engine and cross-ship contract tests pass against independently sourced plans.

## M5 — Public Beta

Make a limited set of verified Cabin Briefings publicly accessible and establish a controlled process for corrections and evidence updates.

**Complete when:** users can inspect provenance and limitations, operational feedback can be handled responsibly, and publication quality is consistent across the supported dataset.
