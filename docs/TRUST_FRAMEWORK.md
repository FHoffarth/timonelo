# Timonelo Trust Framework

---

## 1. Core Philosophy of Trust

Trust is not created through marketing claims or badges.

> **Trust is earned through unyielding epistemic honesty.**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          THE TRUST BALANCE SHEET                            │
│                                                                             │
│   HOW TRUST IS EARNED:                                                      │
│   • Showing an obstructed view before the cruise line discloses it.         │
│   • Displaying an explicit "Unknown" instead of making a guess.             │
│   • Showing true ambient daylight instead of retouched glamour photos.      │
│   • Maintaining absolute non-commercial independence.                       │
│                                                                             │
│   HOW TRUST IS LOST:                                                        │
│   • A single hallucinated socket count or false balcony measurement.        │
│   • Concealing a lifeboat obstruction to make a room look appealing.        │
│   • Accepting referral kickbacks to favor specific cabins or lines.         │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 2. The Evidence Hierarchy (Source Weighting)

Every factual claim in Timonelo must link back to an immutable record in the Evidence Registry, weighted by source authority:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         EVIDENCE HIERARCHY TIERS                            │
│                                                                             │
│  TIER 1 (Weight: 1.0) ── Primary Shipyard General Arrangement (GA) Blueprints│
│                          & Official Naval Builder Drawings.                 │
│  TIER 2 (Weight: 0.9) ── Timonelo Direct On-Site Photographic & Laser        │
│                          Surveys (Standardized focal length & metadata).    │
│  TIER 3 (Weight: 0.7) ── Verified Contributor Field Evidence                │
│                          (Double-corroborated, unedited physical photos).   │
│  TIER 4 (Weight: 0.4) ── Official Cruise Line Marketing Cutaways & Schematics│
│                          (Treated with caution; frequently inaccurate).     │
│  TIER 5 (Weight: 0.0) ── Unverified third-party blogs or forum rumors        │
│                          (DISALLOWED AS CANONICAL EVIDENCE).                │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## 3. The Sacred "Unknown"

Missing information is an **active, first-class state**.

When evidence is missing for a cabin's bed placement, socket layout, or exact square footage:
1. The interface renders an honest, clean architectural silhouette.
2. The limitation is stated plainly: *"Bed placement unverified on this deck. Awaiting verified stateroom survey."*
3. The platform never interpolates, guesses, or uses artificial filler data.

---

## 4. Multi-Source Provenance Standard

No stateroom attribute can be certified as **Verified** without passing the **Two-Source Rule**:
- It must be corroborated by at least two independent primary-source evidence vectors (e.g., naval GA drawing + physical survey photo).
- Every verified attribute retains an immutable link to its evidence IDs in the Knowledge Pack.

---

## 5. Non-Commercial Independence

- **Zero Affiliate Bias**: Timonelo never receives commissions or payments from cruise lines for inventory sales.
- **Zero Sponsored Ranks**: No cruise line or travel agency can pay to alter stateroom attributes, remove noise warnings, or promote specific ships.
- **Independence as a Moat**: Because Timonelo has no financial incentive to flatter, its data is accepted as objective truth.
